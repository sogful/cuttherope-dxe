# Android legacy reference

The private Android fork history is connected to this repository by merge
commit `3a41383e`, whose second parent is the former fork tip `90fe6a5`.

This directory keeps only the Android host files, launcher resources, build
helpers, and custom asset candidates that are useful during migration. The old
fork was MonoGame-based, so these files are reference material rather than an
active build target.

Use `git show 90fe6a5:<path>` when another historical file is needed.
